# Provider brand icons

Vendor marks are copied from [`@lobehub/icons-static-svg`](https://github.com/lobehub/lobe-icons) (MIT).
They are used only to identify the corresponding model providers in the settings UI.

Files are inlined with Vite `?raw`; `fill="currentColor"` follows the tile foreground color.
If a provider has no local mark, `ProviderMark` falls back to a gradient tile with its first letter.
